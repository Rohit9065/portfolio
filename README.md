## 🚀 Live Preview & Running Locally

### Option 1: Using the Node.js Server
From this directory (`d:\portfolio`), run:
```bash
node server.js
```
or:
```bash
npm start
```
Then open your browser at:
👉 **[http://localhost:3000](http://localhost:3000)** (or `http://127.0.0.1:3000`)

### Option 2: Direct Browser Opening
You can simply double-click or open `index.html` in any web browser (Chrome, Edge, Firefox, Brave). No build tools or installations are required!

## 🌐 How to Generate a Public Online Portfolio Link

### 1. Free GitHub Pages (Recommended: `https://rohit9065.github.io/portfolio`)
1. Create a new repository on your GitHub account named `portfolio` (or `rohit9065.github.io`):
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   git branch -M main
   git remote add origin https://github.com/Rohit9065/portfolio.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings** > **Pages** > Under **Branch**, select `main` and `/ (root)` > Click **Save**.
3. Within 1-2 minutes, your live portfolio will be public at:
   `https://rohit9065.github.io/portfolio/`

---

### 2. Free Vercel Deployment (Instant Global CDN)
1. Install or run Vercel CLI:
   ```bash
   npx vercel
   ```
2. Follow the 3 prompt questions (press Enter for defaults).
3. Vercel will instantly generate a live production link (e.g. `https://rohit-raj-gupta.vercel.app`)!

---

### 3. Free Netlify Deployment (Drag-and-Drop)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `d:\portfolio` folder directly onto the page.
3. Your live link is generated in 10 seconds!
